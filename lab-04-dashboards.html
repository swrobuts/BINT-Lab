Dashboard-DesignDashboard Design

Ein gutes Dashboard kommuniziert Erkenntnisse schnell und klar. Diese Prinzipien helfen dabei, visuelle Überladung zu vermeiden und den Fokus auf das Wesentliche zu legen. A good dashboard communicates insights quickly and clearly. These principles help avoid visual overload and keep focus on what matters.

01

Data-Ink Ratio (Tufte)

Nur nötige visuelle Elemente verwenden. Jede Tinte muss Daten repräsentieren – kein Dekor, keine Verzierungen. Use only necessary visual elements. Every drop of ink must represent data – no decoration, no ornaments.

02

5-Second Rule

Die Kernaussage des Dashboards muss in 5 Sekunden erkennbar sein. Wenn Nutzer suchen müssen, scheitert das Design. The key message of the dashboard must be recognizable within 5 seconds. If users need to search, the design has failed.

03

Visual Hierarchy

Wichtigstes oben links, Details unten rechts. Nutzer lesen Dashboards wie Text – in Z-Mustern. Most important content top-left, details bottom-right. Users read dashboards like text – in Z-patterns.

04

Farbe sparsam einsetzenUse Color Sparingly

Max. 3–4 Farben, mit semantischer Bedeutung (Rot = schlecht, Grün = gut). Farbe zur Hervorhebung, nicht zur Dekoration. Max. 3–4 colors, with semantic meaning (red = bad, green = good). Color for emphasis, not decoration.

Gestalt-Prinzipien im Dashboard-DesignGestalt Principles in Dashboard Design

Die Gestalt-Prinzipien (Nähe, Ähnlichkeit, Geschlossenheit, Kontinuität) beeinflussen, wie Nutzer visuelle Gruppen wahrnehmen. KPIs, die zusammengehören, sollten räumlich nahe platziert werden (Nähe); gleiche Chart-Typen signalisieren Vergleichbarkeit (Ähnlichkeit). The Gestalt principles (proximity, similarity, closure, continuity) influence how users perceive visual groups. KPIs that belong together should be placed close to each other (proximity); similar chart types signal comparability (similarity).

BarrierefreiheitAccessibility

Ca. 8 % der Männer haben eine Rot-Grün-Schwäche. Verwenden Sie farbenblind-sichere Paletten (z. B. Viridis, Cividis) und ergänzen Sie Farben durch Muster oder Beschriftungen. WCAG 2.1 empfiehlt ein Kontrastverhältnis von mindestens 4,5:1. Approx. 8% of men have a red-green colour deficiency. Use colourblind-safe palettes (e.g. Viridis, Cividis) and supplement colour with patterns or labels. WCAG 2.1 recommends a minimum contrast ratio of 4.5:1.

import plotly.express as px
import pandas as pd

df = pd.read_csv('train.csv', encoding='latin-1')

# Scatter: Umsatz vs. Bestellanzahl je Sub-Kategorie
# Der Datensatz enthaelt als einzige Kennzahl 'Sales'. Eine zweite
# Dimension gewinnt man durch Aggregation - hier die Zahl der Positionen.
by_sub = df.groupby(['Category', 'Sub-Category']).agg(
    Umsatz=('Sales', 'sum'),
    Positionen=('Order ID', 'count')
).reset_index()

fig3 = px.scatter(
    by_sub,
    x='Positionen',
    y='Umsatz',
    color='Category',
    text='Sub-Category',
    size='Umsatz',
    title='Umsatz vs. Bestellpositionen je Sub-Kategorie'
)
fig3.update_traces(textposition='top center')
fig3.show()

Plotly Dash

Plotly Dash ist ein Python-Framework zum Erstellen vollständiger Web-Dashboards. Es verbindet ein Flask-Backend mit einem automatisch generierten React-Frontend. Das Layout ist deklarativ, die Reaktivität wird durch Callbacks gesteuert. Plotly Dash is a Python framework for building complete web dashboards. It connects a Flask backend with an automatically generated React frontend. The layout is declarative and reactivity is controlled through callbacks.

Architektur-KonzepteArchitecture Concepts

App

Flask-Backend + React-Frontend (automatisch generiert). Dash übernimmt die gesamte Infrastruktur. Flask backend + React frontend (automatically generated). Dash handles the entire infrastructure.

Layout

Deklarativ wie HTML, aber als Python-Objekte. html.Div(), dcc.Graph(), dcc.Dropdown() usw. Declarative like HTML, but as Python objects. html.Div(), dcc.Graph(), dcc.Dropdown() etc.

Callbacks

Reaktivität durch @app.callback: Input → Python-Funktion → Output. Ähnlich wie Event-Listener. Reactivity via @app.callback: Input → Python function → Output. Similar to event listeners.

Vollständige Dash-App (app.py)Complete Dash App (app.py)

# app.py – Vollständiges Dash-Dashboard
import dash
from dash import dcc, html, Input, Output
import plotly.express as px
import pandas as pd

app = dash.Dash(__name__)
server = app.server  # Nötig für gunicorn app:server
df = pd.read_csv('train.csv', encoding='latin-1')

app.layout = html.Div([
    html.H1('Sales Dashboard', style={'fontFamily': 'Space Grotesk', 'color': '#1E3A8A'}),

    html.Label('Kategorie auswählen:'),
    dcc.Dropdown(
        id='category-filter',
        options=[{'label': c, 'value': c} for c in df['Category'].unique()],
        value=df['Category'].unique()[0],
        clearable=False
    ),

    dcc.Graph(id='subcategory-chart'),
    dcc.Graph(id='orders-scatter')
], style={'maxWidth': '1200px', 'margin': '0 auto', 'padding': '2rem'})


@app.callback(
    Output('subcategory-chart', 'figure'),
    Input('category-filter', 'value')
)
def update_bar(category):
    filtered = df[df['Category'] == category]
    sales_by_sub = filtered.groupby('Sub-Category')['Sales'].sum().reset_index()
    fig = px.bar(
        sales_by_sub,
        x='Sub-Category',
        y='Sales',
        title=f'Umsatz nach Sub-Kategorie: {category}',
        color_discrete_sequence=['#2563EB']
    )
    return fig


@app.callback(
    Output('orders-scatter', 'figure'),
    Input('category-filter', 'value')
)
def update_scatter(category):
    filtered = df[df['Category'] == category]
    by_sub = filtered.groupby('Sub-Category').agg(
        Umsatz=('Sales', 'sum'),
        Positionen=('Order ID', 'count')
    ).reset_index()
    fig = px.scatter(
        by_sub,
        x='Positionen',
        y='Umsatz',
        text='Sub-Category',
        size='Umsatz',
        title=f'Umsatz vs. Bestellpositionen: {category}',
        color_discrete_sequence=['#0D9488']
    )
    fig.update_traces(textposition='top center')
    return fig


if __name__ == '__main__':
    app.run(debug=True)
